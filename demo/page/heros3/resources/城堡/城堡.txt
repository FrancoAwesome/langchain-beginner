一、城堡族兵种全阶解析

1. 枪兵 / 戟兵（一级兵）
‌基础定位‌：前期主力肉盾 + 输出兼备。
‌属性优势‌：攻防平衡，造价低廉，在一级兵中综合实力名列前茅。
‌特技亮点‌：
‌夙敌‌：对黑暗骑士、恐怖骑士有额外伤害加成，体现“长枪克骑兵”的战术逻辑。
‌无惧‌：免疫恐惧类状态，稳定性强。
‌实战用途‌：常列阵前排，为后方远程单位（如神射手）提供保护。

2. 弓箭手 / 神射手（二级兵）
‌升级形态‌：弓箭手 → 神射手（可手动升级）。
‌核心价值‌：两次射击能力，使其成为前期清野效率最高的远程单位之一。
‌战术地位‌：即便后期拥有大天使，神射手仍能发挥余热，是多线发育的关键支撑。
‌操作建议‌：配合枪兵推进，避免单独暴露在敌方远程火力下。

3. 狮鹫 / 皇家狮鹫（三级兵）
‌飞行单位‌：具备空中机动性，可越过障碍发起攻击。
‌特技核心‌：‌无限反击‌，在防守时极具压制力，尤其克制依赖近战反击的阵容。
‌综合评价‌：攻防速属性全面领先同级兵种，是中期战场的中坚力量。
‌战略延伸‌：常用于攻城战中突入城内，打乱敌方阵型。

4. 剑士 / 十字军（四级兵）
‌定位‌：高输出近战单位，被誉为“四级兵中的输出机器”。
‌战斗机制‌：拥有“双击”特效，爆发极高，通常在骑士诱敌后出手收割。
‌风险提示‌：虽输出爆炸，但阵亡率较高，需合理安排出手顺序。

5. 僧侣 / 祭司（五级兵）
‌常被低估‌：许多人认为其平庸，实则潜力巨大。
‌真实价值‌：
拥有稳定的远程攻击能力，前期开拓表现可靠。
资源紧张时无需升级即可投入实战，性价比突出。
‌战术意义‌：在高手手中，祭司能有效弥补远程火力空缺，是“冷板凳上的隐藏王牌”。

6. 骑兵 / 骑士（六级兵）
‌核心英雄‌：塔里斯便是以骑士身份统领骑兵的传奇将领，擅长冲锋陷阵。
‌技能搭配‌：【领导术】+【战术】构成人族骑兵的“黄金搭档”。
领导术提升部队士气。
战术技能决定冲锋成败，直接影响战斗节奏。
‌实战作用‌：后期主要作战力量，兼具输出与控制能力。

7. 天使 / 大天使（七级兵）
‌终极单位‌：人气最高、数据最强、价格最贵的七级兵。
‌核心能力‌：
‌复活‌：可复活己方阵亡单位，极大提升续航能力。
‌士气提升‌：增强全军战斗意志。
‌高攻防与极速‌：30点攻防、极高速度，堪称“七级兵之王”。
‌战略地位‌：一旦成型，便是全军核心，常被称为“大爹级”单位。

二、城堡族整体战术风格
城堡族的兵种体系堪称教科书级别，呈现出清晰的成长曲线：

‌前期‌：枪兵+神射手组合快速清野，积累资源。
‌中期‌：狮鹫+剑士形成突击力量，压制对手远程单位。
‌后期‌：骑士+大天使构成主力，祭司补足远程火力，形成多维打击。
‌关键结论‌：城堡族并非依赖单一“超模”兵种取胜，而是通过‌兵种协同 + 节奏推进‌实现全面压制。其战术逻辑更贴近现实军事体系，适合技术型玩家深入挖掘。
